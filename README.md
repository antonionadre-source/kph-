# Kraken Properties & Facilities Management

Sitio React, TypeScript, Vite, Tailwind y Express, con seis idiomas y SEO dinámico.

Usa Node.js 24:

```sh
npm ci
npm run dev
```

Abre <http://localhost:3000>. Para producción: `npm run build` y `npm start`.
Configuración privada en `.env.local`, partiendo de `.env.example`. El sitio se
puede navegar sin claves; Firebase usa emuladores en local y EmailJS/Make quedan
desactivados hasta configurar servicios de prueba.
